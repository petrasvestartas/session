# Session Viewer — feature inventory (audit Phase 2)

Scope: `session/session_viewer` at the 2026-11-19 checkout. Read-only audit: nothing was built or run; every row comes from reading or grepping the cited source. Paths are relative to `session_viewer/` unless they start with `../`. Line numbers were re-checked for a sample of rows; small drift (a few lines) is possible elsewhere.

**Status** = Implemented / Partial / Missing after tracing the code path (a command or button alone does not count). **UNVERIFIED** marks a consequence read from code but not observed in a run.

**Tests**: counts are `#[test]` attributes found by grep (677 in `src/`, 61 `#[ignore]`), not pass/fail. CI (`../.github/workflows/viewer-check.yml`) runs only `cargo check` (wasm32 lib, native all-targets) and `cargo xtest`. The 52 Playwright files `tests/*.cjs` (+7 `tests/*.py`) run by hand against `trunk serve` (port 8770) and are **not in CI**; 8 of them `require('../docs/extensions/browser.cjs')`, which does not exist (`docs/extensions/` holds only `nested.pb`, `nested.yaml`): `color-channels`, `docked-workspace`, `editing-extensions`, `large-object-dragging`, `layer-workspace`, `live-shell-editing`, `source-editing`, `splitting`.

**Tutorial**: `docs/journey/<id>.md` pages of the current course (`docs/journey/course.json`, 1,298 steps; many short ids are one-line redirects to a consolidated subject page). Historical lesson pages are `docs/archived/NN-*.md` with checkpoint sources in `docs/lessons/NN/` (`docs/lessons/SERIES.txt`); per `.claude/rules/viewer-docs.md` they are reconstruction inputs, not the current sequence.

Sources merged here: an earlier draft of the interaction, interface and automation tables (sections 2, 5, 6, spot-checked and corrected, see §8; the draft was deleted) plus new sections 1, 3, 4, 7.
