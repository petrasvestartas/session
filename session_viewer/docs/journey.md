# Build a viewer you can explain

Build one program from a blank GPU frame to the production Session Viewer. Follow the [nine cumulative subjects](journey/active.md) in order. Mathematics follows the first egui painting; scene integration follows camera, rows, rendering and decoding.

Each checkpoint retains earlier implementations. Later subjects add declared module registrations and their own implementations. The final checkpoint compiles its own complete viewer source and production startup page. It does not link to a prebuilt viewer runtime.

The course is still incomplete: executable and browser checks have scoped evidence, while teaching coverage and complete-course acceptance remain open. Read the [acceptance status](journey/active.md#acceptance) before treating a subject as finished.

Historical reconstruction remains available with its source snippets, fixtures, recovery identifiers and checks. Its [former route](archived/cumulative-route-20261115.md) is archived; its 1,298 checkpoints are not the active implementation queue. Historical validation failures remain failures and are not replaced by new checkpoint results.

Start with [Open a GPU frame](journey/completion-frame.md). Use the [foundations](foundations.md) when a Rust concept needs more practice and [Maintaining](maintaining.md) for the exact build and verification commands.
