# Build a viewer you can explain

Build one program from a blank GPU frame to the production Session Viewer across the [17 code-first tutorials and 9 cumulative assemblies](journey/active.md) in order. Mathematics follows the first `egui` painting; scene integration follows camera, rows, rendering and decoding.

Each checkpoint retains earlier implementations. Later subjects add declared module registrations and their own implementations. The final checkpoint compiles its own complete viewer source and production startup page. It does not link to a prebuilt viewer runtime.

Every production and support source file (`388 / 388`) is included in full via `--8<--` and bound by SHA-256 to its tutorial prose witness; browser/mobile human acceptance remains tracked in [Acceptance](journey/active.md#acceptance).

Historical reconstruction remains available with its source snippets, fixtures, recovery identifiers and checks. Its [former route](archived/cumulative-route-20261115.md) is archived; its 1,298 checkpoints are not the active implementation queue. Historical validation failures remain failures and are not replaced by new checkpoint results.

Start with [Tutorial 1: Project architecture and browser initialization](journey/tutorial-one-startup.md). Use the [foundations](foundations.md) when a Rust concept needs more practice and [Maintaining](maintaining.md) for the exact build and verification commands.
