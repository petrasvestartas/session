# Maintaining this site

Not part of the course. Build and check:

```sh
docs/serve.sh build
python3 docs/check_site.py
python3 docs/course_pages.py --audit
docs/serve.sh
```

- Lesson code never lives in the Markdown. A `<!-- file: NN path -->` directive names a checkpoint and a file; the build cuts the block from the verified patch series in `docs/reconstruction/`.
- `course_pages.py --audit`: every checkpoint change is taught exactly once, and typing each lesson reproduces its checkpoint. `Cargo.lock` is generated by Cargo and never taught.
- `check_site.py`: links, downloads, lexers.
- `reconstruction/step_checks.py` runs `cargo check` after every step; `step_status.py` writes the result into each lesson's "Does it compile yet?" line.
- `locator.py` regenerates the per-step maps (`<!-- locator: off -->` in a lesson skips it); `diagrams.py` renders the D2 flowcharts; `check_svg.py` and `check_illustrations.cjs` check the illustrations; `theme.py` renders `theme.css`.
