# Rebuild the course's missing Session inputs

This standalone crate builds four original Session protobuf files with the actual `session_rust` kernel. It needs no viewer, GPU, screenshots, Linux temporary files or learner workspace. It writes to `session_viewer/assets/pb` by default; one optional argument chooses another directory. `course-fixtures.json` records fresh SHA-256 hashes and byte lengths.

These are reconstructed deterministic specimens. The historical binary files and their generated UUIDs were not available. Their old screenshots and rendering evidence cannot establish acceptance of these newly generated bytes.

| Output | Tracked source and preserved contract |
| --- | --- |
| `course-comparison.pb` | `../code/94-declare-the-rendering-comparison-contract-01.rs`: the same two boxes, two cylinders, dimensions, translations and blue colour from `comparison::specimen`. Fixed object/tree identities replace the original lazy UUIDs. |
| `course-metadata.pb` | `../code/96g-prove-exact-metadata-and-definition-round-trips-01.rs`: comparison solids plus exact `FloorBuilder` JSON, `component-original`, `original-edge`, and opaque `custom-glue` bytes. |
| `course-instance-features.pb` | `../code/69i-check-sharing-precision-history-and-release-02.rs`, `../code/96v-project-definition-and-per-instance-features-06.rs`, and `../checks/browser/instance-features.cjs`: one triangle-backed `prototype` Element definition, its `prototype-axis`, and `First`/`Second` references with `instance-feature-0/1`. The browser specimen uses nearby placements (-0.6/+0.6), retains the second lock, and separates each cut from the shared axis so the Attributes toggle has a visible witness. The distant-coordinate unit-test specimen remains unchanged. |
| `course-feature-pick.pb` | `../code/96y-address-feature-pixels-to-original-cad-owners-05.rs` and `../checks/browser/feature-original-pick.cjs`: two box-backed Elements with independent original cut lines away from the boxes; `Pick locked` is translated by +2 and locked. The original browser click coordinates remain `(0.5,0.4,0.2)` and `(2.5,0.4,0.2)`. |

`ordered_mesh.rs` changes map ordering during protobuf encoding only. It preserves every field of the kernel's Mesh message and asserts the decoded message equals the original. All geometry comes from kernel constructors. The generator builds each fixture twice and requires identical bytes before writing it. The output manifest has no timestamp, so unchanged source and kernel versions produce an identical manifest too.

Run from the repository root in PowerShell. The integrator owns the guarded queue; these commands compile Rust and are heavy jobs. On the first checkout, create the local Cargo lockfile, then retain it for subsequent locked runs:

```powershell
$env:REGEN_PROTO = '0'
$env:CARGO_BUILD_JOBS = '1'
$guard = 'session/session_tests/scripts/run-guarded.cmd'
$manifest = 'session/session_viewer/docs/journey/fixtures/Cargo.toml'
& $guard -TimeoutSeconds 600 -ManifestPath "$env:TEMP\course-fixture-lock.json" cargo generate-lockfile --manifest-path $manifest
& $guard -TimeoutSeconds 1200 -ManifestPath "$env:TEMP\course-fixture-build.json" cargo run --locked --manifest-path $manifest -j1
```

Preserve the generated lockfile and the four output hashes as the local input identity. Re-run the executable into a second directory and compare hashes across processes before treating generation as reproducible. No build or generation was performed when this generator was introduced.

Then materialize the unchanged course endpoint with its dependency command. Run the existing Native source/archive/instance-feature/copy-owner checks and the unchanged `instance-features.cjs` and `feature-original-pick.cjs` browser chains. In particular verify two original instance owners, four derived paths, one shared definition, independent attribute visibility, locked-owner rejection, exact feature-pixel selection, and Save/Open regeneration. These fresh checks, followed by the declared matched rendering checks, remain required; generator round trips do not replace them.
