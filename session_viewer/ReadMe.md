# session_viewer

## Guide

1. open terminal
2. go to folder:
   ```
   cd session_viewer
   ```
3. build app:
   ```
   cargo build
   ```
4. run app:
   ```
   cargo run
   ```
5. fast app (no debug):
   ```
   cargo run --release
   ```

done. fire good.
