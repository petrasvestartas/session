# Get the code

**Windows:** install [Git for Windows](https://git-scm.com/download/win) first — it gives you
**Git Bash** (run every command in it), plus `git` and `curl`. `curl` ships by default on
Windows 10+ / macOS; minimal Linux: `sudo apt install -y curl`.

```bash
git clone --recurse-submodules https://github.com/petrasvestartas/session.git
```
